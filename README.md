# Monthly Generator

다이어리 먼슬리 속지와 A4 큰 달력을 만들어 PDF로 저장하는 편집 도구예요. 설치 없이 브라우저에서 바로 써요.

**바로 쓰기:** https://mov-ie.github.io/monthly-generator/

## 할 수 있는 것

- **속지 (2면 1달):** 왼쪽 면에 월 표시 열과 3일, 오른쪽 면에 4일. 기본 크기는 86×171mm예요.
- **연간 달력:** 한 장에 1년 12달. 속지 크기나 A4로 만들고, 월 이름(January / Jan / jan / 1), 글자 굵기와 배율을 고를 수 있어요.
- **A4 큰 달력:** 한 장에 한 달, 일주일 7칸. 가로나 세로, A4나 A3로 만들 수 있어요.
- **날짜형 / 만년형:** 연도와 날짜가 찍힌 버전, 또는 숫자를 직접 적는 빈 버전.
- **빨간날:** 일요일과 한국 공휴일(대체공휴일 포함, 2026~2030년)을 표시해요. 원하는 날짜를 직접 추가할 수도 있어요.
- **스타일:** 달 표시(1 / 01 / jan / 1 jan.), 주 시작 요일, 폰트, 글자 크기, 기울임, 선 색과 굵기, 글자 색.
- **출력 배치:** 속지 크기 그대로 저장하거나, A4·A3 한 장에 여러 쪽을 재단선과 함께 배치해요. 단면과 양면을 고를 수 있어요.

## 공휴일 자동 업데이트

빨간날은 공공데이터포털의 **한국천문연구원 특일 정보 API**에서 받아 와요.

- 매달 1일 GitHub Actions가 작년부터 2년 뒤까지의 공휴일을 받아 `holidays.json`에 저장해요. 대체공휴일, 임시공휴일, 선거일도 들어가요.
- 사이트는 열 때마다 `holidays.json`을 읽어요. 그래서 새로 지정된 공휴일도 따로 손대지 않아도 반영돼요.
- 파일을 내려받아 컴퓨터에서 바로 열면 `holidays.json`을 못 읽어서, 페이지 안에 들어 있는 자료(2025~2030년)를 써요.

**처음 한 번 설정**
1. [공공데이터포털](https://www.data.go.kr)에서 "한국천문연구원_특일 정보"를 활용 신청하고 인증키를 받아요.
2. 이 저장소의 **Settings → Secrets and variables → Actions → New repository secret**에서 이름은 `HOLIDAY_API_KEY`, 값은 인증키로 등록해요. 인코딩 키와 디코딩 키 중 어느 쪽이든 돼요.
3. **Actions → Update holidays → Run workflow**로 한 번 실행해 보면 바로 갱신돼요.

## 사용법

1. 페이지를 열어요.
2. 왼쪽 패널에서 **형태**를 고르세요: 속지 2면, 큰 달력, 연간.
3. 연도, 시작 월, 끝 월을 정하고 달 표시, 폰트, 색, 여백을 원하는 대로 바꾸세요. 오른쪽 미리보기가 바로 바뀌어요.
4. 속지라면 **출력 용지**를 고르세요.
   - **속지 크기:** 86×171mm 같은 실제 크기로 한 쪽씩 저장해요. 인쇄소에 맡기거나 그 크기 용지에 바로 인쇄할 때 써요.
   - **A4 / A3:** 한 장에 여러 쪽을 배치해요. 방향을 **자동**으로 두면 가장 많이 들어가는 방향을 골라요. 86×171mm는 A4 가로에 3쪽이 들어가요.
5. 맨 아래 **PDF로 저장 / 인쇄**를 누르고, 인쇄 창에서 **PDF로 저장**을 고르세요.

설정은 브라우저에 저장돼서 다음에 열어도 그대로예요. 처음 상태로 돌리려면 **처음 설정으로 되돌리기**를 누르세요.

### 폰트 안내

기본 폰트는 Futura예요. 컴퓨터에 Futura가 있으면(맥에는 기본으로 있어요) Futura로 나오고, 없으면 비슷한 무료 폰트 Jost로 나와요. 다른 폰트를 쓰려면 **폰트 → 직접 입력**에 컴퓨터에 설치된 폰트 이름을 적으세요.

## 프린트 팁

**인쇄 창 설정**
- 배율은 **100% (실제 크기)**로 두세요. "용지에 맞추기"가 켜져 있으면 속지가 줄어들어요.
- 여백은 **없음**으로 하세요.
- **머리글과 바닥글**을 끄세요. 날짜나 주소가 같이 찍히지 않아요.
- **배경 그래픽**을 켜세요. 빨간날 색이 유지돼요.
- 용지 크기가 속지나 A4로 자동으로 잡히지 않으면 **Chrome**으로 열어 보세요. 크기가 가장 정확하게 나와요.

**양면 인쇄 (링 바인더 속지)**
- 출력 배치를 **양면**으로 하면, 낱장 앞면에 이번 달 오른쪽 면, 뒷면에 다음 달 왼쪽 면이 오도록 앞뒤를 맞춰 줘요. 자르고 순서대로 끼우면 펼쳤을 때 한 달이 마주 보여요.
- 첫 낱장 앞면은 비어 있어서 표지로 쓸 수 있어요.
- 세로 배치는 **긴 쪽 넘기기**, 가로 배치는 **짧은 쪽 넘기기**로 출력하세요. 패널에도 안내가 나와요.

**처음 뽑을 때**
- 한 장만 먼저 뽑아서 자로 크기를 재 보세요.
- 양면이면 빛에 비춰 앞뒤 칸이 맞는지 확인하세요. 프린터에 따라 1~2mm 어긋날 수 있어요.
- 링 구멍 자리는 **안쪽 여백**으로 조절해요. 기본은 6mm예요.

**재단과 용지**
- 재단선을 켜면 각 쪽 모서리 바깥에 자를 위치가 표시돼요. 커터 칼과 자를 쓰면 깔끔해요.
- 프린터는 보통 가장자리 3~5mm를 못 찍어요. **프린터 안전 여백**에 그 값을 넣어 두면 잘리지 않게 배치해요.
- A5 속지를 A4 한 장에 2쪽 넣으려면 안전 여백을 0으로 해야 해요. 테두리 없는 인쇄가 되는 프린터에서만 쓰세요. 아니면 A3를 고르거나 A5 용지에 바로 인쇄하세요.
- 만년필을 쓴다면 100g 이상 종이가 뒷비침이 적어요.
